## 概念对照表（自己攒，考试前一页就够）

| 容易混的一对 | 正确说法 |
| --- | --- |
| 行列式 vs 矩阵 | 行列式是数；矩阵是表。`\|kA\| = kⁿ\|A\|`，`A` 是 n 阶 |
| `AB = O` | 推不出 `A = O` 或 `B = O`（矩阵有零因子） |
| 初等行变换 | 不改秩，**会改行列式的值** |
| `(AB)ᵀ` | `= BᵀAᵀ`，顺序要反 |
| `(A+B)²` | 需 `AB = BA` 才等于 `A² + 2AB + B²` |
| 齐次方程组只有零解 | ⟺ `r(A) = n`（列满秩）；未知数 n > 秩 r 时必有非零解 |
