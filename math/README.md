| --- | --- | --- |
| `错题本-高数.md` | 高数（5 学分，俞挺）做错的题 | 当天作业里错的，当晚记一行 |
| `错题本-线代.md` | 线代（2 学分，陈娟）做错的题 | 同上 |

## 一行一题，就记三件事

1. **错在哪一步**（不是"粗心"——"粗心"等于没写）
2. **正确做法是什么**（一句话，比如"泰勒展开到 x³"）
3. **哪天重做**，重做结果打 ✓ 或 ✗

> 重做 ✗ 的挪到下一周，不许划掉。
> 一本错题本的价值不在"记了多少"，在"重做了几遍"。

## 每周日 30 分钟

把这一周的错题从头重做一遍：

- 做对 → 打 `✓`
- 做错 → 保留，挪到下周
- 连续两周对的 → 可以整行删掉（恭喜）
