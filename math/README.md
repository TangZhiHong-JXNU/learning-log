## 一行一题，就记四件事

1. **错在哪一步**（不是"粗心"——"粗心"等于没写）
2. **失分类型**（A 不会 / B 不熟 / **C 算错** / **D 漏条件** / **E 格式**；线代另有 **F 概念混**）
3. **正确做法是什么**（一句话，比如"泰勒展开到 x³"）
4. **哪天重做**，重做结果打 ✓ 或 ✗

> 重做 ✗ 的挪到下一周，不许划掉。
> 一本错题本的价值不在"记了多少"，在"重做了几遍"。

## 为什么"失分类型"这一列最关键

他的目标是**高数与线代都往 100 靠**（10-05 定：两门都要 100，启动日 10/7）。而从 85 分往 100 分走，**战场全在 C、D、E 三类**——会做但算错、会做但漏条件、会做但格式扣分。这三类**跟智力无关，只跟习惯有关**，是唯一靠努力就能拿到的分数。

**但两门课的主犯不是同一个**：

- **高数**：主犯是 **C（算错）**，靠**每天 10 分钟限时计算 + 双路验算**治
- **线代**：主犯是 **F（概念混）**，靠**每周日默写概念对照表**治——线代里这一类的优先级**最高**，不是最低

**所以每两周统计一次"这半个月哪一类最多"（两门分开统计）**，用数据决定下一步练什么（而不是凭感觉）。
详见 `../../数学底稿/09-满分路线图-从会做到拿满.md`（高数）和 `../../数学底稿/10-线代满分路线图与双百策略.md`（线代 + 双百策略）。
