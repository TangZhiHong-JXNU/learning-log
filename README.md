# learning-log

江西师范大学 · 微电子学院 · 电子信息类 2026 级
大学四年的代码学习记录，从 2026 年 10 月开始。

## 这个仓库是干什么的

**它是给三年后的自己攒的证据。**

2029 年投夏令营时，简历上写"熟悉 C 语言"这句话所有人都会写，等于没写。
而这个链接点开，老师看到的是从 week01 到 week16 **连续 16 周、每周都有提交的记录**——那不是自述，是证据。

所以规则只有一条：**写了代码就提交，不许攒着。**

## 目录结构

```
c-lang/
  week01/   猜数字游戏
  week02/   ...
```

（每完成一周，回来更新这一行）

## 每次提交的三行命令

```
git add .
git commit -m "week01 猜数字游戏"
git push
```

commit 信息写清楚这一周做了什么，别写 `update`。

## 三条纪律

1. 每行代码自己敲，看懂 ≠ 会写
2. 每周至少提交一次，空的提交记录也是记录
3. 别把密码、密钥、几 MB 以上的大文件传上来
