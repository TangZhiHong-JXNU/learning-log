# journal · 每日复盘

**规则只有一条：每天晚上花 3 分钟，回答 3 个问题。**

不是为了写日记，是为了让"我今天到底有没有进步"这件事**有证据**。面试时别人问"你最近做了什么"，你能翻开这个文件直接说。

---

## 三问模板（复制到当天文件里）

```markdown
# YYYY-MM-DD（周X）

## 今天做了什么
- 看课：（翁恺第几讲，几倍速）
- 代码：（文件名 + 大约几行）
- 其他：（高数/英语/社团…）

## 卡在哪
（只写一个点，写清楚 —— 这是明天要解决的东西）

## 明天第一件事
（只写一件事，具体到"打开哪个文件、做什么"）

## 提交情况
- [ ] 今天有 commit（github.com/TangZhiHong-JXNU）
```

---

## 三条纪律

1. **卡住超过 20 分钟就停**，把它写进"卡在哪"，然后去问我或者去做下一件。磨一晚上不叫努力，叫消耗。
2. **"明天第一件事"必须具体**。"明天学指针"不合格；"明天把 guess.c 的 while 循环改成 do-while"合格。
3. **当天必须有 commit**。哪怕只写了一道题、改了一个 bug。**提交不断，比学多少更能决定你能不能撑到面试。**
