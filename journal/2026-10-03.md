# 2026-10-03 复盘：文档怎么转成 PDF 交作业

今天把「电子信息大类实践导论」第一次作业从零做到发出去。
这篇不写心得，专记**操作层面的坑**——这些东西以后四年每次交作业都用得上。

---

## 一、转 PDF 踩的 7 个坑

### 1. 在「预览界面」里改文档 → Ctrl+A / Ctrl+S 全部失灵
现象：标题变成蓝色居中，`---` 被画成一条横线。
真相：那是**只读的渲染视图**，不是编辑器。
**规则：预览 = 只能看，不能改。** 要改就回 VS Code 的编辑区。

> 我连续两次遇到"按键没反应"，其实是同一个原因。

### 2. 打开的是 `.md` 而不是 `.txt` → `#` 和 `---` 会被打进 PDF
markdown 里的 `#` 是排版指令，Word / WPS 不认，会原样印出来。
**规则：交作业用纯文本版 `.txt`，`.md` 只是写作用的草稿。**

### 3. Ctrl+A 全选没反应
两种可能：焦点不在正文 / 当前是只读视图。
**兜底操作**：先在正文里点一下鼠标，再按 `Ctrl+A`；
还不行就走菜单：**开始 → 编辑 → 选择 → 全选**，或者干脆用鼠标拖。

### 4. 不知道怎么居中
**`Ctrl+E`** 就是居中。
配套：Ctrl+L 左对齐 / Ctrl+R 右对齐 / **Ctrl+J 是两端对齐**（容易按错，按下去字会被拉开）。

### 5. 找不到导出按钮
WPS 里三条路都能出 PDF：
- **文件 → 输出为 PDF**
- `Ctrl+P` → 打印机选 **「导出为 WPS PDF」**
- `F12` 另存为 → 保存类型选 **PDF 文件 (\*.pdf)**

### 6. 导出后在桌面找不到文件
**WPS 默认把 PDF 存到它的云盘**，不是桌面：
```
C:\Users\34008\WPS Cloud\WPSDrive\1316010268\WPS云盘\
```
**规则：导出前先看清保存位置。** 实在找不到就在资源管理器里搜文件名。

### 7. 导出时文档里还留着选区
如果导出前文字还是蓝底高亮（处于选中状态），WPS 可能只导出那一部分。
**规则：导出前在正文里点一下，取消选区。**

## 二、发邮箱踩的 5 个坑

### 1. 附件没传完就点发送
上传要时间。**等附件列表里显示文件名和大小**（比如 138 KB）再点发送，
否则老师收到的是空附件。

### 2. 文件名写错
老师要求的是 **`唐志鸿+学号`**，有两个地方容易错：
- 漏掉中间那个 **`+`**（`Shift` + 等号键）
- **学号打错** —— 学号错一位，老师归档时直接对不上人

### 3. 以为"删除"能撤回
QQ 邮箱的删除**只删自己邮箱里的记录，老师的收件箱那封还在**。
而"撤回"功能**只对发往 QQ / Foxmail 邮箱的信有效**，发到 aliyun.com 撤不回来。

### 4. 发错之后的正确补救
**补发一封正确的，正文里说明一句**：
> 老师您好，刚才那封有误，请以本封为准，给您添麻烦了。

老师不会因为收到两封扣分，**装作不知道才会**。

### 5. 发件人显示的是网名
QQ 邮箱默认用 QQ 昵称发送。
**设置 → 账户 → 发件人昵称 → 改成真名**，改一次永久生效。

## 三、还没搞定的一件事

**学号到底是多少，明天必须核实清楚。**

- 我这边一直记的是 `202623061209`
- 今天文件名里出现的是 `202629301209`

两个只差两位，但**学号不能猜**。这不是一次作业的署名问题，
以后交作业、报名竞赛、推免材料全都要用同一串数字。

**核实办法**（任意一个）：教务系统个人信息页 / 校园一卡通 / 录取通知短信。
核完告诉我，我把所有文件里的学号统一订正。

## 四、一句话记住今天

> **`.md` 是草稿，`.txt` 才是交作业用的；预览只能看不能改；
> 导出先看清存哪儿；发之前把文件名念一遍念出来。**
