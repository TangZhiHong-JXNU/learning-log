## 一、一句话讲完这节

> **`else if` 不是新语法，它只是 `else { if ... }` 的简便写法。**

```c
if (x < 0) {          /* 完整写法：一层套一层 */
    f = -1;
} else {
    if (x == 0) {
        f = 0;
    } else {
        f = 2 * x;
    }
}
```

把 `else {` 和 `if` 合并、"}` 和它前面的 `}` 合并，就变成了：

```c
if (x < 0) {          /* 级联写法：一条直线 */
    f = -1;
} else if (x == 0) {
    f = 0;
} else {
    f = 2 * x;
}
```

**两种写法逻辑完全等价** —— 我用你的 gcc 跑了五组数据验证：

| x | 嵌套版 | 级联版 |
|---|---|---|
| -5 | -1 | -1 |
| -1 | -1 | -1 |
| 0 | 0 | 0 |
| 1 | 2 | 2 |
| 5 | 10 | 10 |

**为什么值得用级联？** 嵌套写法每多一层就往右缩一格，五个分支要缩进五格；
级联**永远只有一层缩进**，代码排成一条直线，一眼看全。

## 二、这节的例题：分段函数

翁恺的例子是这种（数学上叫分段函数）：

```
f(x) = -1   (x < 0)
        0   (x = 0)
        2x  (x > 0)
```

标准写法就是上面那段 `if / else if / else`。

**注意最后一个 `else` 是"剩下的全部"** —— 它对应 `x > 0`（前面两条都不成立的情形）。
这就是 3.2.4 那节讲的：**有了 else 兜底，每种情况都有人赋值，不会漏出初始值。**

## 三、级联的关键执行规则（这节的真东西）

> **自上而下逐条判断，命中第一条就停，后面的全部跳过。**

这一条带来两个必须知道的后果：

### 后果 1：条件的顺序决定对错

我把成绩等级的判断写了两个版本跑了一次：

| 分数 | 从大到小写（对） | 从小到大写（错） |
|---|---|---|
| 95 | A | **D** |
| 85 | B | **D** |
| 75 | C | **D** |
| 65 | D | D |
| 55 | E | E |

右边那版只是把条件顺序倒过来，结果**60 分以上的全成了 D**。

**为什么？** 因为 `95 >= 60` 成立，第一条就命中了，**后面三条根本没机会执行**。

> **写级联时养成习惯：条件要么从最严格往宽松写（如先 90 再 80），要么先想清楚每条会不会"吃掉"后面的。**

### 后果 2：级联永远只走一支

级联是"多选一"——**多个分支里一定且只会执行一个**。所以不用担心写了两条会都执行，
但也别指望它能同时处理两件事（那种情况要用两个独立的 if）。

## 四、翁恺强调的第二种好处：单一出口

级联的配合**先算出结果、最后统一输出**：

```c
int f = 0;
if (x < 0) {
    f = -1;
} else if (x == 0) {
    f = 0;
} else {
    f = 2 * x;
}
printf("f=%d\n", f);      /* 只有这一句 printf */
```

对比在每个分支里各写一句 printf：

```c
if (x < 0) {
    printf("f=-1\n");
} else if (x == 0) {
    printf("f=0\n");
} else {
    printf("f=%d\n", 2*x);
}
```

**后者能跑，但不好。** 差别在于：

| | 单一出口 | 分支里各打印 |
|---|---|---|
| printf 有几处 | 1 处 | 3 处 |
| 想改输出格式（比如加个空格） | 改一行 | 改三行，容易漏一处 |
| 想"算出值但不急着输出" | 可以 | 做不到 |

**这也是为什么你 PAT 那些题要先把答案算出来、最后一句 printf 收尾。**

## 五、级联 vs 嵌套 vs switch（什么时候用哪个）

| 场景 | 用什么 |
|---|---|
| 3~5 个互斥区间（分数等级、月份分段、分段函数） | **级联 `else if`** ✅ |
| 每个分支里还要再细分（比如先分性别、再分年龄段） | 嵌套 |
| 判断同一个变量的**离散值**（`type == 1 / 2 / 3`） | switch-case（下一节 3.3.4） |

翁恺给的实用建议：**嵌套不要超过三层**，超过了就该考虑重构成级联或 switch。
