# 翁恺 3.3.1 嵌套的 if-else

> 视频全名：**3.3.1 嵌套的 if-else：在 if 或 else 后面要执行的还是 if 语句**，时长 11 分 36 秒
> 下一节：3.3.2 级联的 if-else（6 分 09 秒）

---

## 一、这节讲什么

**嵌套 = if 的成立分支或不成立分支里，放的还是一条 if 语句。**

```c
if (条件A) {
    if (条件B) { ... } else { ... }   /* 里面又是一整套 if-else */
} else {
    if (条件C) { ... } else { ... }
}
```

翁恺的规矩：

> **if 或 else 后面只能跟"一条语句"——而一条 if 语句也算一条语句。**
> 所以嵌套在法律上是合法的，不用额外加括号也不会报错。

---

## 二、这节真正要你记住的：else 的匹配规则

### 规则（一句话）

> **else 总是和离它最近的、还没有 else 的那个 if 匹配。**
> **缩进不能暗示匹配。**

### 翁恺的原例（我实测过）

```c
int gameover = 0, count = 10;

if (gameover == 0)
    if (count > 20)
        printf("A win");
else                        /* 你以为它属于第一个 if */
    printf("B win");        /* 实际它属于第二个 if */
```

**你以为的逻辑**：游戏没结束(gameover==0) 且 count>20 → A 赢；否则 → B 赢。

**实际的逻辑**：else 跟第二个 if 配对，所以是：

```
if (gameover == 0) {
    if (count > 20) 打印 A win
    else            打印 B win      /* else 在这里 */
}
```

### 实测结果（你的 gcc 跑出来的）

| gameover | count | 陷阱版输出 | 加了大括号版输出 |
|---|---|---|---|
| 0 | 30 | `A win` | `A win` |
| 0 | 10 | **`B win`** ← 错 | （什么都不打印） |
| 1 | 30 | （什么都不打印）← 错 | `B win` |

看第 2 行：`gameover = 0` 表示**游戏还没结束**，结果却打印了 "B win"。
看第 3 行：`gameover = 1` 表示**游戏已结束**，反而**什么都不打印**。

**两行全反了。**

### 好消息：编译器会提醒你

这个例子编译时 gcc 会给出一条 warning：

```
warning: suggest explicit braces to avoid ambiguous 'else' [-Wparentheses]
```

**看到 `-Wparentheses` 这个字，就是编译器在说"你这里的 else 归属不明确，加括号吧"。**
但这只是 warning，程序照样编译、照样运行、照样出错。

---

## 三、解法（也是 3.2.5 那节的同一条）

> **在 if 和 else 后面总是用 `{}`，即使只有一条语句。**

加完括号，代码变成你脑子里想的那个意思：

```c
if (gameover == 0) {
    if (count > 20) {
        printf("A win");
    }
} else {
    printf("B win");
}
```

**注意大括号的位置决定了 else 归谁**——第一个 `}` 把内层 if 关在里面，
外层的 `else` 就只能跟最外面的 `if` 配对了。

---

## 四、这节的另一个例子：三个数求最大值

翁恺课堂上的写法（嵌套版）：

```c
int max = 0;
if (a > b) {
    if (a > c) {
        max = a;
    } else {
        max = c;
    }
} else {
    if (b > c) {
        max = b;
    } else {
        max = c;
    }
}
```

我跑了四组数据验证：

| a | b | c | 嵌套版 | 级联版 |
|---|---|---|---|---|
| 3 | 7 | 5 | 7 | 7 |
| 7 | 3 | 5 | 7 | 7 |
| 5 | 5 | 2 | 5 | 5 |
| 1 | 2 | 3 | 3 | 3 |

两种写法结果一样。**嵌套版更"笨"但思路直白**（先比 a、b，赢家再跟 c 比），
**级联版（3.3.2 会讲）更短**。`max = 0` 只是兜底，这里每个分支都赋了值，所以 0 永远不会漏出来。

---

## 五、嵌套的两个实操建议

1. **嵌套不要超过 3 层。** 超过之后没人能看懂，包括三天后的你自己。
2. **内层 if 尽量写成"带 else 的完整形态"**，避免中间哪条路没给变量赋值
   （就是 3.2.4 那个 `max = 0` 漏出来的坑）。
