# if 与 switch 写法格式速查

> 配合翁恺 3.2.x ~ 3.3.x。看不懂的地方回到视频，不用死记。

---

## 一、if 家族（四种形态）

### 1. 单 if —— 满足条件才做

```c
if (条件) {
    语句;
}
```

### 2. if-else —— 二选一

```c
if (条件) {
    语句A;
} else {
    语句B;
}
```

### 3. 级联 if-else if —— 多选一（最常用）

```c
if (条件1) {
    语句A;
} else if (条件2) {
    语句B;
} else if (条件3) {
    语句C;
} else {
    语句D;        /* 上面的都不满足才走这里 */
}
```

> 它是 `else { if ... }` 的缩写，所以**中间的 else 不能省**。

### 4. 嵌套 if —— if 里面还有 if

```c
if (条件1) {
    if (条件2) {
        语句;
    }
}
```

## 二、if 的硬规则

| 规则 | 说明 |
|---|---|
| 条件必须放**圆括号**里 | `if x > 0` ❌ → `if (x > 0)` ✅ |
| 只有一条语句时大括号**可省** | 但**别省**（3.2.5 讲过：加了分号、多了语句都会出事） |
| `else` 匹配**最近的未配对 if** | 不确定就加 `{}` 强制配对 |
| 级联是**自上而下，命中即停** | 顺序写反会全错（比如先判 `>60` 再判 `>90`） |
| 最后的 `else` 可以省 | 但省了就可能"都没命中" → 变量没被赋值 |

## 三、switch 格式

```c
switch (控制表达式) {        /* 只能是整型：int / char */
    case 常量1:
        语句;
        break;
    case 常量2:
        语句;
        break;
    case 常量3:
    case 常量4:              /* 多个值共用一段，靠"落空" */
        语句;
        break;
    default:                 /* 兜底，建议写 */
        语句;
        break;
}
```

### 对照例子：成绩分级（week01/score.c）

```c
score /= 10;                 /* 降维：101 种压缩成 11 种 */
switch (score) {
    case 10:
    case 9:  printf("A\n"); break;   /* 10 落空到 9，共用这段 */
    case 8:  printf("B\n"); break;
    case 7:  printf("C\n"); break;
    case 6:  printf("D\n"); break;
    default: printf("E\n"); break;
}
```

---

## 四、switch 的硬规则

| 规则 | 说明 |
|---|---|
| 控制表达式**只能是整型** | `double`、`char 数组`（字符串）都不行 |
| `case` 后必须是**常量** | 不能写变量，不能写范围（`case x > 0` ❌） |
| `break` 别漏 | 漏了会**落空**到下一个 case，继续执行 |
| `case -1` 负数合法 | case 只要求是整型常量 |
| `default` 建议写 | 相当于 if 的最后一个 else |

---

## 五、什么时候用哪个

| 场景 | 用哪个 |
|---|---|
| 判断**范围**（x > 0、x < 0、x >= 60） | **if** |
| 判断**等于**几个固定值 | **switch** |
| 分支 2~3 个 | **if**（switch 的优势体现不出来） |
| 分支很多、且都是离散值 | **switch** |
| 浮点、字符串比较 | **if**（switch 不支持） |

> 判断标准：**能不能把值压成有限几个？** 能 → switch；不能（是区间）→ if。

## 六、三个新手必踩的坑

**① 把 `==` 写成 `=`**

```c
if (a = 1)     /* 错：这是赋值，条件是永真 */
if (a == 1)    /* 对 */
```
> 加 `-Wall` 编译时 gcc 会警告，看到警告一定要看。

**② switch 忘了 break → 落空**

```c
case 7: printf("C\n");      /* 没 break，会继续往下执行 case 6 */
case 6: printf("D\n"); break;
```

**③ if 后面多打了分号**

```c
if (x > 0);        /* 分号让 if 变成"什么都不做" */
    printf("正数"); /* 这行永远执行 */
```

---

## 七、一句话记牢

> **if 管"在哪一段"，switch 管"等于几"。**
> 分支少用 if，离散值多才用 switch。
