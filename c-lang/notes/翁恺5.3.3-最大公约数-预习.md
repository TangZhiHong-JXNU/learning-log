### 8.1 三行赋值的顺序，错了会怎样

以 `a = 12, b = 18` 为例（本机实测）：

| 写法 | 结果 | 评价 |
| --- | --- | --- |
| `t = a % b;  a = b;  b = t;` | **6** | ✓ 正确 |
| `a = b;  t = a % b;  b = t;` | **18** | ✗ 第一步就把 a 覆盖了，`a % b` 算的已经是新 a |
| `t = a % b;  b = t;  a = b;` | **0** | ✗ b 先被覆盖成余数，原来的 b 丢了 |
| `t = a % b;  a = b;`（漏掉 `b = t;`） | **死循环** | ✗ a、b 永远不变，条件永远成立 |

> **一句话记住**：`t` 存在的唯一理由，就是**先把「还需要用、但马上要被覆盖」的那个值存起来**。
> 所以「算余数」必须在「覆盖」之前，「交班」必须在「两边都还没被改坏」的时候完成。

### 8.2 手算追踪（a = 12, b = 18）

```
开始：       a=12   b=18
一轮之后：   a=18   b=12   t=12
一轮之后：   a=12   b=6    t=6
一轮之后：   a=6    b=0    t=0
b 变成 0 → 结束，答案就是 a = 6
```

注意第一轮：`12 < 18`，`12 % 18 = 12` —— 余数就是 12 本身，于是 `a` 和 `b` 正好对调了一下。
**这就是「不需要提前比较大小」的原因**：如果前小后大，第一轮会自动把它们换过来。

### 8.3 结果对照

```
输入 12 18   -> gcd = 6
输入 18 12   -> gcd = 6     （顺序无关）
输入 6  18   -> gcd = 6     （其中一个是另一个的因子）
```

### 8.4 三句话，回答「凭什么」（三个预习问题的正解）

**① 换了一对数，答案凭什么不变？** —— 因为 `gcd(a, b) = gcd(b, a % b)`。

设 `r = a % b`，按带余除法的定义 `a = b×q + r`：

- 若 `d` 同时整除 `a` 和 `b` → `d` 必整除 `a - b×q = r` → `d` 也同时整除 `b` 和 `r`
- 反过来，若 `d` 同时整除 `b` 和 `r` → `d` 必整除 `b×q + r = a` → 也同时整除 `a` 和 `b`

**两边的「公约数集合」是同一批数**，所以其中最大的那个也相同。

本机实测（100 和 75）—— 直接打印每一步的公约数集合：

```
(100, 75)   公约数 = { 1, 5, 25 }
(75, 25)    公约数 = { 1, 5, 25 }
(25, 0)     公约数 = { 1, 5, 25 }
```

**② 为什么停在 `b == 0`？** —— 因为 `gcd(a, 0) = a`。

`0` 能被任何数整除（`0 % i` 恒为 0，从不失败），所以「还得能整除 0」这条要求**等于什么都没要求**；
条件只剩「能整除 `a`」，而一个数最大的约数就是它自己。

**③ 为什么一定停得下来？** —— 因为余数每轮都严格变小。

带余除法保证 `0 ≤ r < b`，而下一轮的 `b` 就是这一轮的 `r` → **新 b 严格小于旧 b**。
`b` 是非负整数且一路递减 → 有限步内必定撞到 0，不可能无限转。

### 8.5 输入顺序的代价：最多 1 轮

本机实测八组，比较 `(a,b)` 与 `(b,a)` 的轮数：

| a | b | 轮数(a,b) | 轮数(b,a) | 差 |
| --- | --- | --- | --- | --- |
| 12 | 18 | 3 | 2 | 1 |
| 48 | 18 | 3 | 4 | 1 |
| 7 | 13 | 4 | 3 | 1 |
| 100 | 75 | 2 | 3 | 1 |
| 123456 | 7890 | 7 | 8 | 1 |
| 1000000 | 999999 | 2 | 3 | 1 |
| 89 | 144 | 11 | 10 | 1 |
| 1000 | 7 | 3 | 4 | 1 |

**差恒为 1** —— 前小后大总是多绕一轮（第一轮的 `a % b = a`，恰好在做对调）。
所以「不预先比较大小」的代价可以忽略，代码因此短了一截。

### 8.6 这节真正带走的一件事

**同一个问题，可以有好几层解法。** 枚举法的正确性肉眼可见，路线 B 的正确性要**证明**。
考试、面试里能写出路线 A 的人一大把，能说清路线 B「为什么是对的」的人少得多 ——
**这就是为什么它是本节的正题。**
