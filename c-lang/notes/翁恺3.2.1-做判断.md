## 一、视频里的代码（时间差 + 借位）

```c
#include <stdio.h>

int main(void)
{
    int hour1, minute1;
    int hour2, minute2;

    scanf("%d %d", &hour1, &minute1);
    scanf("%d %d", &hour2, &minute2);

    int ih = hour2 - hour1;
    int im = minute2 - minute1;

    if (im < 0) {
        im = 60 + im;
        ih--;
    }

    printf("时间差是%d小时%d分。\n", ih, im);
    return 0;
}
```

## 三、逐行拆开讲

### ① `if (im < 0)` —— 括号里是"问句"

```c
if (条件) {
    只有条件成立时才执行的语句
}
```

- **条件是一个表达式**，C 会算出它的值
- 值 **非 0（通常是 1）= 成立**，**0 = 不成立**

实测：

```c
printf("%d\n", 5 > 3);    // 1
printf("%d\n", 5 == 3);   // 0
```

**C 语言没有 true / false 这种专门的"布尔类型"**，它拿整数 1 和 0 当真假用。这是 C 的老习惯，一直沿用至今。

### ② 大括号 `{ }` —— 决定"管多少句"

```c
if (im < 0) {
    im = 60 + im;      // 这两句都被 if 管着
    ih--;
}
```

**不写大括号，if 只管紧跟着的那一行：**

```c
if (im < 0)
    im = 60 + im;      // 只这句受保护
    ih--;              // 这句无条件执行 → bug
```

翁恺的建议是**永远写大括号**，哪怕只有一句。我也强烈建议这样 —— 省下的那 10 个字符不够排一次错。

### ③ `ih--` —— 自增自减（你学过，2.2.4）

`ih--` 就是 `ih = ih - 1`。

**借位的含义**：分钟不够减（10 − 20 = −10），就从小时那儿"借"一个小时变成 60 分钟 → 分钟变成 50，小时少 1。

```
13:10 − 11:20
= (13−1):(10+60) − 11:20
= 12:70 − 11:20
= 1:50
```

## 四、关系运算符（六个）

| 符号 | 意思 | 例子（a=5, b=3） |
|---|---|---|
| `>` | 大于 | `a > b` → 1 |
| `<` | 小于 | `a < b` → 0 |
| `>=` | 大于等于 | |
| `<=` | 小于等于 | |
| `==` | **等于** | `a == b` → 0 |
| `!=` | 不等于 | `a != b` → 1 |

**⚠️ 头号大坑：`==` 和 `=` 是两回事**

| 写法 | 含义 | 后果 |
|---|---|---|
| `if (a == b)` | **比较**：a 和 b 相等吗 | 正常判断 ✅ |
| `if (a = b)` | **赋值**：把 b 的值塞进 a | 永远成立（只要 b 不是 0）❌ |

第二种编译器**只给 warning，照样编译通过**，然后你的判断永远为真。这是我见过最多的新手 bug 之一。

**防身写法**：把常量放左边 —— `if (5 == a)`。这样万一写成 `if (5 = a)`，编译器会直接报错（不能给常量赋值）。

## 五、优先级两个坑（实测）

```c
printf("%d\n", 5 > 3 == 6 > 4);   // 输出 1
printf("%d\n", 6 > 5 > 4);        // 输出 0   ← 数学上明明是对的！
```

**`6 > 5 > 4` 为什么是 0？** 因为从左往右算：

```
6 > 5  →  1
1 > 4  →  0   ← 第二步拿这个 1 去跟 4 比
```

**所以永远不要写 `a < b < c` 这种连写。** 想表达"b 在 a 和 c 之间"，必须拆开：

```c
if (a < b && b < c)     // && 是"并且"，稍后一节会讲
```

另外记住：

> **算术 > 关系 > 赋值**
> `int r = a > 0;` 是先比较再赋值，不是反过来。

## 六、光有 if 不够时：加 else

if 可以单独用（不成立就跳过），也可以在后面接 else：

```c
if (bill >= price) {
    printf("应该找您：%d\n", bill - price);
} else {
    printf("你的钱不够\n");
}
```

**两个分支只会走一个**，不会都执行。
