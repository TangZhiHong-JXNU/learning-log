# 翁恺 3.2.4 求两个数的最大值 —— 四种写法实测对比

> 核心问题：**为什么条件不成立时 max 输出的是 0，而不是 a 或 b？**

---

## 一、先纠正一个说法

`int max = 0;` 里的 **0 不是"条件不成立时的输出"，它是初始值（initial value）**。

变量就像一个盒子，你得**先往里放个东西**，后面才敢去用它。
C 语言规定：**局部变量如果不初始化，里面是上一次内存残留的垃圾值**。
（我实测：故意不初始化时，max 打印出来是 `1`，不是 0，也不是 5。）

所以 `= 0` 只是程序员给盒子垫的一个底，**防止没人管它的时候里面是脏东西**。

---

## 二、关键规则：if 不成立 = 什么都不做

```c
if (a > b) {
    max = a;
}
// 没有 else，条件不成立时：直接跳过去，一行都不执行
```

**C 不会自动帮你"输出相反的那一个"。** 没有 `else`，就没有"否则"这条路。
计算机只做你**明确写下**的事，不会替你补全逻辑。

---

## 三、四种写法，我用你的 gcc 全跑了一遍

| a | b | ① 有 else | ② 先假设 b | ③ 两个独立 if | ④ 只写一个 if |
|---|---|---|---|---|---|
| 7 | 3 | **7** | **7** | **7** | **7** |
| 3 | 7 | **7** | **7** | **7** | **0** ❌ |
| 5 | 5 | **5** | **5** | **0** ❌ | **0** ❌ |

四种写法分别是：

```c
/* ① 有 else：最稳妥 */
int max = 0;
if (a > b) { max = a; } else { max = b; }

/* ② 先假设 b 最大：翁恺说这版更巧妙 */
int max = b;
if (a > b) { max = a; }

/* ③ 两个独立 if（没有 else）：a == b 时漏了 */
int max = 0;
if (a > b) { max = a; }
if (a < b) { max = b; }

/* ④ 只写一个 if：a <= b 时全错 */
int max = 0;
if (a > b) { max = a; }
```

**看第三行 a == b：** ①② 拿到 5（正确），③④ 拿到 0（初始值原封不动）。

---

## 四、为什么"不成立"不等于"反过来"

这是这节最重要的思维点。

> `a > b` 不成立，推出来的是 **`a <= b`** ——
> 它包含**两种**情况：`a < b` **和** `a == b`。

所以"条件不成立就取另一个"这句话本身就不严谨：**不成立时有两条可能的路**。

只不过在"求最大值"这道题里，两种情况的答案碰巧一样：
- `a < b` → 最大值是 b
- `a == b` → 取 a 或 b **都行**（一样大）

**这就是 ① 为什么能工作**：else 分支里写 `max = b`，把上面两种情况一锅端了。

而 ③ 用 `if (a < b)` 单独写一条，**只覆盖了 `a < b`，把 `a == b` 漏掉了** —— 漏掉的那次，max 从头到尾没被赋值，只能交出初始值 0。

---

## 五、结论（一句话）

**初始值 0 不是"答案"，是"没人管它时的兜底值"。**
写判断时，必须保证**每一种情况都有人给 max 赋值** —— 要么加 `else` 兜住剩下的全部，要么一开始就把初始值设成某个候选答案（`max = b`）。
