## 要交的东西（这是简历上的那一行）
`score_manager.c` —— **学生成绩管理系统**，约 300 行：

- 学生结构体：`学号 / 姓名 / 高数 / 线代 / 英语`（可加总分与平均分）
- 功能：录入、显示全部、按学号或姓名查询、修改、删除、按总分排序（冒泡）
- 文件：`score.dat`（文本方式）保存与载入，程序启动自动读盘，退出自动存盘
- 交互：字符菜单循环，输入非法要能提示而不是崩溃
