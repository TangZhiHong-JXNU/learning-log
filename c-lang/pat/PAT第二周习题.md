## 7-1 厘米换算英尺英寸（15 分）

如果已知英制长度的英尺 `foot` 和英寸 `inch` 的值，那么对应的米是
`(foot + inch/12) × 0.3048`。现在，如果用户输入的是厘米数，
那么对应英制长度的英尺和英寸是多少呢？别忘了 1 英尺等于 12 英寸。

**输入格式：** 输入在一行中给出 1 个正整数，单位是厘米。

**输出格式：** 在一行中输出这个厘米数对应英制长度的英尺和英寸的整数值，中间用空格分开。

**输入样例：**
```
170
```

**输出样例：**
```
5 6
```

> 💡 这题是你昨天那个 `英尺英寸换算.c` **反过来**：昨天是「英尺英寸 → 米」，今天是「厘米 → 英尺英寸」。

## 7-2 然后是几点（15 分）

有时候人们用四位数字表示一个时间，比如 `1106` 表示 11 点零 6 分。
现在，你的程序要根据起始时间和流逝的时间计算出终止时间。

读入两个数字，第一个数字以这样的四位数字表示当前时间，第二个数字表示分钟数，
计算当前时间经过那么多分钟后是几点，结果也表示为四位数字。
当小时为个位数时，没有前导的零，即 5 点 30 分表示为 `530`。
**注意，第二个数字表示的分钟数可能超过 60，也可能是负数。**

**输入格式：** 输入在一行中给出 2 个整数，分别是四位数字表示的起始时间、以及流逝的分钟数，其间以空格分隔。

**输出格式：** 输出四位数字表示的终止时间。题目保证起始时间和终止时间在同一天内。

**输入样例：**
```
1120 110
```

**输出样例：**
```
1310
```

### 自测数据（不只要过样例）

| 输入 | 应该输出 | 在考什么 |
|---|---|---|
| `1120 110` | `1310` | 官方样例 |
| `530 -10` | `520` | **负数**（流逝分钟可以是负的） |
| `1120 -110` | `930` | 负的且跨过整点 |

> 💡 关键提示：**这题不用 `if` 也能做**。
> 先把 `1120` 拆成 11 点 20 分，全部换成"从零点起的总分钟数"，
> 加上流逝分钟，再换回四位数。这样进位借位自动搞定，不用判断。

## 7-3 逆序的三位数（5 分）· 顺手也能做

程序每次读入一个正三位数，然后输出逆序的数字。
注意，当输入的数字含有结尾的 0 时，输出不应带有前导的 0。比如输入 700，输出应该是 7。

**输入格式：** 每个测试是一个 3 位的正整数。

**输出格式：** 输出逆序的数。

**输入样例：**
```
123
```

**输出样例：**
```
321
```

> 💡 两把钥匙：`%10` 拿到个位数，`/100` 拿到百位数。中间那位要靠这两个组合出来。
