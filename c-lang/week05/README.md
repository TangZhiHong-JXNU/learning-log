# week05 · 指针（D6–D7，10/4–10/5）

## 目标
地址与取值、`*` 与 `&`、指针与数组的关系、指针做函数参数（真正能改外部变量）、`malloc` / `free`。

## 要交的东西
- `reverse.c` —— 用指针（不许用下标）实现数组逆置
- `swap.c` —— `swap_wrong`（值传递，改不动）和 `swap_right`（传地址）两个版本放一起，注释写清为什么
- `sort_dyn.c` —— 用 `malloc` 按运行时输入的 n 申请数组，排序后 `free`

## 自测（面试必背）
1. 指针变量里存的到底是什么？（**门牌号类比**）
2. `int *p; *p = 10;` 为什么危险？
3. 数组名能被赋值吗？`sizeof(arr)` vs `sizeof(p)` 差在哪？
4. `malloc` 之后为什么要 `free`？`free` 之后为什么要置 NULL？
5. `p+1` 移动多少字节？取决于什么？
